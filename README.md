# Copione — Editor per il teatro

App web (un unico file HTML, nessuna installazione richiesta) per scrivere copioni teatrali: struttura in atti e scene, personaggi, note d'attore, didascalie, numerazione automatica delle battute, versioni salvate ed esportazione in PDF formattato professionalmente.

## Uso online
Se pubblicata con GitHub Pages, l'app è raggiungibile all'indirizzo:
`https://<tuo-utente>.github.io/<nome-repository>/`

## Uso in locale
Basta aprire `index.html` in un browser: non serve alcun server o installazione.

## Salvataggio dati
I copioni vengono salvati automaticamente nel browser. Per portare il lavoro su un altro dispositivo, usa "Salva progetto (.json)" e poi "Importa progetto" sull'altro computer.
